Proyubi は、受託開発会社や中小規模の SIer 向けのオープンソースのプロジェクト管理ツールです。

- **セルフホスト版（無料・オープンソース）**: GNU AGPL-3.0 ライセンスで公開します。
- **クラウド SaaS 版（有料）**: 開発予定です。

### 開発予定の方向性

以下はいずれも開発予定であり、現時点では実装されていません。

- **要件変更の影響分析（AI 支援・開発予定）**: 要件変更による影響の分析と、矛盾の検出アラートを、根拠となる出典を示した上で提示します。内容は人が承認してから反映します。
- **顧客向け進捗レポート（開発予定）**: レポート内の数値がチケットまでさかのぼって確認できる進捗レポート。

Proyubi 是一款面向日本受托开发公司（受託開発）和中小型系统集成商（SIer）的开源项目管理工具。

### 提供形式

- **自托管版（免费、开源）**：以 GNU AGPL-3.0 许可证发布。
- **云端 SaaS 版（付费）**：计划中。

### 计划中的方向

以下内容均为计划中，目前尚未实现。

- **需求变更影响分析（AI 辅助，计划中）**：分析需求变更带来的影响并提示矛盾，同时附上来源引用；经人工批准后才会应用。
- **面向客户的进度报告（计划中）**：报告中的数字可追溯到对应的工单。

## English

Proyubi is an open-source project management tool for Japanese contract development firms (受託開発) and small system integrators (SIers).

### Editions

- **Self-hosted edition (free, open source)**: released under the GNU AGPL-3.0.
- **Cloud SaaS edition (paid)**: planned.

### Planned directions

Everything below is planned and not implemented yet.

- **Requirement-change impact analysis (AI-assisted, planned)**: impact analysis and contradiction alerts for requirement changes, with source citations. Changes are applied only after a human approves them.
- **Client-facing progress reports (planned)**: reports whose numbers trace back to tickets.

### Status

The code is being migrated into this repository. The repository is not yet usable.
