# Proyubi brand assets

The blue P symbol and app/favicon variants are retained as the Proyubi product mark.
All horizontal and vertical wordmarks now read **Proyubi**; the old Pullcord letter outlines have been replaced, not merely relabeled in metadata.

- `lockup-horizontal*`: horizontal signature, transparent/light, dark-background and monochrome variants.
- `lockup-vertical*`: centered vertical signature in light and dark variants.
- SVG wordmarks use outlined lettering and do not require a client font. Corresponding PNG files are rendered from the same SVG at 2×.
- `mark*`, `app-icon*`, `favicon*`: existing standalone P symbol, with no old product name.

Compatibility: public asset filenames are stable; the web build hashes logo contents for cache busting.
