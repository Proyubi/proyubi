# Claude デスクトップに PM アシスタントをつなぐ（PM ユーザー向け）

**対象：** Claude デスクトップアプリを使う PM・メンバーの方
**所要：** 3 分・**専門知識も、ファイルの準備も不要**

---

## 結論：JSON ファイルは要りません

Claude に PM システムをつなぐのに、**設定ファイル（JSON）を作る必要はありません。**
やることは「**コネクタ画面に URL を 1 本貼る**」だけです。

> 💡 なぜこの案内をするか：Claude の設定には似た画面が 2 つあります。
> **「開発者 → ローカル MCP サーバー」**（“設定を編集” で JSON をいじる画面）は**使いません**。あれは開発者がPCでプログラムを動かす用です。
> 使うのは **「コネクタ」** の画面。下の手順どおりに進めてください。

---

## 事前に必要なもの（1 つだけ）

**あなた専用の接続 URL。** PM システムにログインし、**「設定 → MCP設定」タブ**を開くと表示されます（コピーボタンあり）。

```
https://mcp.example.com/t/あなた専用トークン/mcp
```

- これは**あなた専用の鍵**です。**他人に共有しないでください。**
- 漏れた場合は同じ「設定 → MCP設定」画面の「URL を再発行」で無効化できます。
- 画面に出ない場合は管理者に確認してください。
- 対応プラン：Claude の **Free / Pro / Max / Team / Enterprise**。
  （Free は追加できるコネクタが 1 つまで。Team / Enterprise は「オーナー」権限の方のみ追加可）

---

## 設定手順（画面どおり）

1. Claude デスクトップ左下（またはメニュー）の **設定（Settings）** を開く。
2. 左メニューを下にスクロールし、「カスタマイズ」内の **「コネクタ（Connectors）」** をクリック。
   - ※ すぐ上に「開発者」「ローカル MCP サーバー」がありますが、**そこではありません**。
3. **「カスタムコネクタを追加（Add custom connector）」** ボタンをクリック。
4. 表示された入力欄に、次を入れる：
   - **名前（Name）**：`PM アシスタント`（分かりやすい任意の名前でOK）
   - **URL（リモート MCP サーバー URL）**：「設定 → MCP設定」でコピーした **接続 URL を、末尾の `/mcp` まで丸ごと貼り付け**
5. **「追加（Add）／接続」** をクリック。
6. 一覧に「PM アシスタント」が出て **「接続済み」** の表示になれば完了です。
   - もし認証（ログイン/OAuth）を求められたら、そのまま進めて構いません。通常は URL だけで繋がります。

---

## 使ってみる

1. 新しいチャットを開く。
2. 入力欄近くの **ツール／コネクタのアイコン**から **「PM アシスタント」を ON** にする。
3. あとは日本語で話しかけるだけ。例：

   - 「〇〇プロジェクトのタスク一覧を見せて」
   - 「今、遅れているタスクと、担当が決まっていないタスクを教えて」
   - 「田中さんが今抱えているタスクを一覧にして」
   - 「この要件をタスクに分解して〇〇プロジェクトに登録して」（← 登録前に内容を確認してくれます）
   - 「タスク『マスタ設計』の締め切りを 7/20 に変えて」

> ✅ 登録・変更は**実際に PM システムへ反映**されます。作成/変更の前に Claude が内容を見せてくれるので、**確認してから「OK」**と答えてください。迷ったら「登録せず案だけ出して」と言えば安全です。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| コネクタ画面が見当たらない | Claude アプリを最新に更新。設定 → 「カスタマイズ」の下を確認。 |
| 「接続できない」 | URL を**末尾 `/mcp` まで**正しく貼れているか、前後に空白がないか確認。 |
| 「Unauthorized / 401」 | URL のトークンが違う／失効しています。管理者に**新しい URL**を依頼。 |
| ツールが選べない・反応しない | コネクタを一度削除して再追加。それでもダメなら管理者へ。 |

**管理者へ連絡する際**は、①表示されたエラー文、②貼り付けた URL（トークン部分は伏せてOK）を添えてください。

## （管理者向けメモ）配るのは JSON ではなく URL

PM に配布するのは **接続 URL 1 本**だけです（`https://mcp.example.com/t/<token>/mcp`）。
`claude_desktop_config.json` を配る必要はありません（あれはローカル stdio 型＝開発者向けの方式で、
本番のリモート公開サーバとは別物）。サーバ構築・トークン発行・エッジ設定は
[`pm-mcp/README.md`](../../pm-mcp/README.md) を参照。
