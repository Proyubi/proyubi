# 在 Claude 桌面端连接 PM 助手（中文版）

**只需 3 分钟，不用装任何东西，也不需要 JSON 文件——粘贴一条 URL 就行。**

---

## 你需要准备的（只有 1 样）

**你的专属连接 URL。** 登录 PM 系统后，打开 **「設定 → MCP設定」标签页**即可看到（带复制按钮）：

```
https://mcp.example.com/t/你的专属令牌/mcp
```

- 这是**你个人的钥匙，不要分享给别人。**
- 泄露了就在同一页点「重新生成 URL」使旧的失效。
- 页面里看不到就找管理员确认。
- 支持的套餐：Claude 免费版 / Pro / Max / Team / Enterprise（免费版只能加 1 个连接器）。

---

## 配置步骤

1. 打开 Claude 桌面端 **设置（Settings）**。
2. 左侧菜单往下找到 **「连接器 / コネクタ（Connectors）」** 点开。
   - ⚠️ 不要用旁边的「开发者 / 本地 MCP 服务器」，那是给程序员的。
3. 点 **「添加自定义连接器（Add custom connector）」**。
4. 填两栏：
   - **名称**：`PM 助手`（随便起个好认的名字）
   - **URL**：把管理员给的连接 URL **原样粘贴（一直到末尾的 `/mcp`）**。
5. 点 **「添加 / 连接」**，出现「已连接」就成功了。

---

## 怎么用

在对话里先开启「PM 助手」，然后直接用中文/日文说话，例如：

- 「给我看 〇〇 项目的任务列表」
- 「现在有哪些任务延期了？哪些还没分配负责人？」
- 「把这段需求拆成任务，登记到 〇〇 项目」
- 「把任务『マスタ設計』的截止日改成 7/20」

> 登记和修改会**真正写进 PM 系统**。它会先把内容给你看，**确认没问题再回复「OK」**。

---

## 常见问题

| 情况 | 处理 |
|---|---|
| 连不上 | 检查 URL 是否**完整粘到 `/mcp`**、有没有多余空格。 |
| 提示 Unauthorized / 401 | 令牌错了或已失效，找管理员要**新 URL**。 |
| 找不到连接器菜单 | 更新 Claude 到最新版。 |
