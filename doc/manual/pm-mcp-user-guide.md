# PM アシスタント接続ガイド（ChatGPT / Claude 用）

**対象：** 案件管理（PM）システムを使うプロジェクトマネージャー・メンバーの方
**所要：** 5 分・**専門知識は不要**（URL を貼るだけ）

---

## これは何ができるの？

お使いの **ChatGPT** または **Claude** に、この PM システムを**つなぐ**ための設定ガイドです。
一度つなぐと、普段のチャットで日本語で話しかけるだけで、AI が PM システムを直接読み書きします。例：

- 「〇〇プロジェクトのタスク一覧を見せて」
- 「この要件をタスクに分解して〇〇プロジェクトに登録して」
- 「今、遅れているタスクや担当が空いているタスクを教えて」
- 「田中さんの今の作業量（担当タスク）を一覧にして」
- 「タスク『マスタ設計』の期限を 7/20 に変えて」

> 使うのは**あなたご自身が契約している ChatGPT / Claude** です。新しいアプリの契約は不要です。

---

## 事前に必要なもの（1 つだけ）

**あなた専用の接続 URL。** PM システムの **「設定 → MCP設定」タブ**で取得できます（コピーボタンあり）。こんな形です：

```
https://mcp.example.com/t/xxxxxxxxxxxxxxxx/mcp
```

- この URL は**あなた専用の鍵**です。**他人に共有しないでください。**
- 漏れた場合は「設定 → MCP設定」の「URL を再発行」で無効化できます。画面に出ない場合は管理者へ。

以下、**ChatGPT を使う方**と**Claude を使う方**で手順が分かれます。お使いの方だけ読めば OK です。

---

## 【A】ChatGPT を使う場合

> 対応プラン：ChatGPT の **Plus / Pro / Business / Enterprise**（Web またはデスクトップアプリ）。

### 手順

1. ChatGPT 右上の**プロフィールアイコン → 設定** を開く。
2. 左メニューの **「コネクタ」（Connectors / アプリ）** を開く。
3. 右上あたりの **「詳細設定（Advanced）」** を開き、**「開発者モード（Developer mode）」を ON** にする。
   - ※ この「開発者モード」は ChatGPT に外部ツールをつなぐための正式な設定です。難しい操作はありません。
4. コネクタ画面に戻り、**「作成する / カスタムコネクタを追加（Add / Create）」** を選ぶ。
5. 入力欄に：
   - **名前**：`PM アシスタント`（任意の分かりやすい名前）
   - **URL（MCP サーバー URL）**：「設定 → MCP設定」でコピーした **接続 URL をそのまま貼り付け**
   - **認証**：`なし（No authentication）` を選択（鍵は URL に含まれているため）
6. **「作成 / 接続」** を押す。緑のチェックや「接続済み」が出れば完了です。

### 使い方

新しいチャットで、必要なら入力欄の **「＋」→ 追加したコネクタ（PM アシスタント）を選択**してから、
「〇〇プロジェクトのタスクを見せて」のように話しかけます。

---

## 【B】Claude を使う場合（デスクトップ / Web / スマホ）

> 対応プラン：Claude の **Free / Pro / Max / Team / Enterprise**。（Free は接続できるコネクタが 1 つまで）
> Team / Enterprise では、追加できるのは「オーナー」権限の方だけです。

### ⚠️ 間違えやすいポイント

Claude デスクトップの **設定 → 「開発者」→「ローカル MCP サーバー」** という画面がありますが、
**そこは使いません**（あれは開発者がPC上でプログラムを動かす用です）。
使うのは **「コネクタ」** の画面です。下記の通り操作してください。

### 手順

1. Claude の **設定（Settings）** を開く。
2. 左メニュー（下の方「カスタマイズ」）の **「コネクタ（Connectors）」** を開く。
3. **「カスタムコネクタを追加（Add custom connector）」** を押す。
4. 入力欄に：
   - **名前**：`PM アシスタント`（任意）
   - **URL（リモート MCP サーバー URL）**：「設定 → MCP設定」でコピーした **接続 URL をそのまま貼り付け**
5. **「追加 / 接続」** を押す。「接続済み」になれば完了です。
   - ※ もし認証（OAuth）を求められたら、そのまま進めて構いません。通常は URL だけで繋がります。

### 使い方

チャット入力欄の**ツール／コネクタのアイコンから「PM アシスタント」を有効**にし、
「今週締め切りのタスクを教えて」のように話しかけます。

---

## 何ができて、何に気をつける？

**できること**

- プロジェクト・タスクの**閲覧**（一覧、遅れ・リスク、担当者の作業量）
- タスクの**新規作成・一括作成（WBS ツリー）・部分更新**（名前・期間・担当・進捗など）
- **バグ票の起票・一覧**（品質管理のバグ管理タブと同じもの）。
  「ACME 教務システムに『検索の教室表示が不正』でバグを 1 件、優先度 高、担当は田中さんで起票して」
  のように頼めば登録され、`BUG-004` のような番号が自動で振られます。起票者はあなたになります。

**気をつけること**

- AI は**登録・変更を実際に反映**します。作成/変更の前に AI が内容を提示してくれるので、**中身を確認してから「OK」**と答えてください。
- 変更後は PM システムの Gantt 画面で反映を確認できます。
- 迷ったら「まず一覧を見せて」「登録せず案だけ出して」と伝えると安全です。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「接続できない / エラー」 | URL を**最後まで**正しく貼れているか確認（末尾 `/mcp` まで）。前後の空白も削除。 |
| 「Unauthorized / 401」と出る | URL のトークン部分が違う、または失効しています。管理者に**新しい URL**を依頼してください。 |
| ツールが選べない・出てこない | 一度コネクタを削除して再追加。ChatGPT は「開発者モード」が ON か再確認。 |
| 「404 / つながらない」がしばらく続く | サーバ側メンテの可能性。管理者に連絡してください。 |

**それでも解決しない場合**は、①使っているのが ChatGPT か Claude か、②表示されたエラー文、③貼り付けた URL（トークンは伏せて OK）を添えて管理者へ。

## よくある質問

- **Q. 会社の ChatGPT/Claude じゃなく、個人契約でも使える？**
  → はい。あなたの契約でログインした ChatGPT / Claude に、配布 URL を追加するだけです。
- **Q. スマホの Claude でも使える？**
  → はい。Claude の「コネクタ」に同じ URL を追加すれば、スマホ・Web でも使えます（ChatGPT は主に Web/デスクトップ）。
- **Q. URL を人に見せても大丈夫？**
  → いいえ。URL があれば誰でもあなたの権限で操作できてしまいます。**共有しないで**ください。漏れたら管理者に連絡すれば失効・再発行できます。
