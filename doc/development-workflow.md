# 开发与分支工作方式

- Mac mini 是 Proyubi 主开发机；MBP 为同步/辅助工作副本。
- `main` 保持已验证的非 AI 产品代码。内置 PM 2.0 AI 的规划与后续实现放在 `feature/ai-planning`，不混入当前主线。
- `feature/pm-csv-import` 保留旧仓库未发布的 Jooto CSV 导入计划。
- 旧仓库未提交的独立 Gantt UI 工作另存专用分支；旧版本及完整工作记录保留私密备份，不能直接批量删除。
- 每次发布先提交、测试、核对目标分支/环境，再推送并部署；独立 Proyubi 尚未完成生产切换，不能把旧 PM 的发布授权用于本项目。
- `private/`、实际 env 和密钥只在本机私密保存，不进入 Git。示例配置可跟随代码同步。
- GitHub `Proyubi/proyubi` 当前公开，尚未公开的源代码必须先确认公开范围；不可为了同步把整个私有 monorepo 历史推入公开仓库。
- 数据库、对象存储和生产数据不是 Git 内容。未定义数据范围和目标前，不复制生产数据库、不执行迁移或清空数据。
