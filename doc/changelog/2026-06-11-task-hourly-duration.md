# 2026-06-11 · タスク工期を「時間」単位へ細分化

## ✨ 新功能
- **タスク工期を「日 + 時間」で管理**できるようになりました。期間（日付）に加えて「最終日の作業時間（0–23 時）」を入力でき、「半日だけ」「最終日は数時間」といった短いタスクも正確に表現できます。工期は `6d3h` / `4h` / `30m` のように表示されます。
- **予定 / 実績それぞれに工期**を持てます（予定期間＋予定の最終日時間 / 実績期間＋実績の最終日時間を独立に入力）。
- **工期は「営業日」で計算**します。土日に加え、**祝日**もカウントから除外。祝日は毎週月曜に自動同期（holidays-jp）されるほか、ワークスペースごとに手動で追加・編集・一括取り込みできます。

## 🔧 改进
- WBS 工期列・ガント・進捗ロールアップ（summary / 案件進捗）が、すべて同じ「営業日 + 時間」基準（分単位）で揃いました。マイルストーンの工期列は `—` 表示。
