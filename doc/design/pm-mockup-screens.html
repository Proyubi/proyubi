M1

Claude Code から公開

「このタスクに公開して」と頼むだけ。pm-mcp がローカルの HTML ファイルを読んでアップロードするため、モデルが HTML 全体を出力し直す必要はありません。mockup_id を渡すと同じリンクのまま新しい版になります。
